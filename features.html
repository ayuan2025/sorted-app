妥帖 (Sorted)

随手一拍，纸质文件就收好了。

一款给家庭和个人用的纸质文件、证件收纳工具。发票、合同、证件、票据、说明书， 拍一下就自动整理好、自动认出是什么、自动归进对应的类别，要用的时候一搜就出来。

不用注册，不用登录，不联网，不上云。

能做什么

拍一下就归档

  • 对着纸拍照，自动找到纸的边缘、裁掉多余背景、把歪的扶正、去掉阴影
  • 一张纸可以分好几页拍，合并成一份文件（比如一份合同的第一页、第二页）
  • 也可以从手机相册里挑已有照片导入
  • 保留原始照片，随时可以重新裁剪、旋转

自动认出这是什么

拍完自动读出纸上的文字，判断它属于哪一类，不用你手动选：

  • 证件：身份证、护照、驾驶证、行驶证、社保卡、银行卡、营业执照、不动产权证书
  • 票据：发票、小票、收银条、账单、缴费单
  • 文书：合同、协议、保险保单
  • 生活：说明书、保修卡、快递单、医疗单据、学历证书、房产车辆材料
  • 认不出来的也能自己指定类别，还能新建自己的类别

自动提取关键信息

证件上的重要信息会自动抓出来、单独列好，不用自己抄：

  • 身份证、护照：证件号、姓名、有效期
  • 驾驶证：证号、初次领证日期、准驾车型
  • 行驶证：车牌号、车架号、所有人
  • 银行卡：卡号
  • 营业执照：名称、统一社会信用代码
  • 房产证：不动产权号、权利人

提取出来的号码都经过校验，认错的情况会明显减少。

自动起名字

发票和单据不再叫"扫描件 1"，会自动用机构名称、发票种类这类有用的词当标题。 当然也可以随时自己改。

一搜就找到

  • 搜标题，也搜纸上的全部文字——打发票上的商家名就能把那张发票翻出来
  • 按类别筛选，首页只显示装了东西的类别，界面干净
  • 重要的可以加星标、移进"重要"分组

证件单独上锁

  • 证件类的扫描件在手机里是加密保存的，不是普通图片
  • 可以给整个应用加指纹 / 面容 / 锁屏密码锁

换手机也不怕丢

  • 导出备份包：把所有文件和图片打成一个文件，设个密码，存到你想存的地方
  • 导入备份包：换手机或者重装后，输入密码，一键全部恢复
  • 恢复的证件在新手机上会自动重新加密

完全离线

识别模型就装在应用里，不联网也能用，飞行模式下照样识别中文。

有话想说很方便

  • 设置 → 意见反馈，点一下就直接打开邮件应用，收件人和标题都填好了，你只写内容
  • 遇到识别不准、想要新类别、或者发现了问题，都可以直接发过来

隐私

  • 所有文件只存在你自己手机里，没有任何服务器，不上传任何东西
  • 没有广告，没有数据统计，没有第三方 SDK
  • 证件图片在手机里以密文保存

怎么用

  1. 打开应用，点右下角的 ＋ → 拍一张 / 从相册选
  2. 拍完确认一下，自动归类完成，可以在首页看到
  3. 要找东西就点右上角的 🔍，输入关键词

换手机：设置 → 导出备份包 → 新手机设置 → 导入备份包。 开应用锁：点左上角图标 → 设置。

小提示

  • 拍的时候尽量在光线均匀的地方，纸铺平、四个角都拍进来
  • 备份包的密码忘了就打不开了，没有找回办法，请另外记好
  • 备份文件别和写密码的地方放在一起

目前只有安卓版（Android 7.0 以上），暂不提供 iPhone 版。
