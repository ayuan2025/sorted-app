# 妥帖 · Sorted

**随手一拍，纸质文件就收好了。**

给家庭和个人用的纸质文件、证件收纳工具。发票、合同、证件、票据、说明书，
拍一下就自动整理好、自动认出是什么、自动归进对应的类别，要用的时候一搜就出来。

## 为什么要做这个

起因很朴素：之前用某扫描王扫个证件，先播 30 秒广告，扫完再看一遍开屏，
想导出还得开会员。忍了很久之后，干脆花三天自己写了一个。

所以这个应用有三条硬性原则：

1. **没有广告**，没有开屏，没有「开通会员去水印」
2. **完全离线**，识别模型打进安装包，一张图都不往外传，飞行模式也能用
3. **不用注册登录**，打开就能用

## 它能做什么

- **拍一下就归档**：自动找纸的边缘、裁掉背景、把歪的扶正、去阴影；一份文件可以分好几页拍，合成一份
- **离线识别中文**：识别模型就装在应用里，不联网也能读
- **自动认出是什么**：身份证 / 护照 / 驾驶证 / 行驶证 / 银行卡 / 不动产权证 / 发票 / 合同 / 说明书…，自动归类
- **自动提取关键信息**：证件号、有效期、车牌号、卡号等抓出来单列，并经过校验（VIN 校验位、GB/T 37346-2019 等）
- **自动起名字**：发票单据用机构名、票据种类当标题，不再叫「扫描件 1」
- **全文搜索**：搜标题，也搜纸上的全部文字
- **证件加密保存**：证件类扫描件在手机里以密文存放，密钥存在手机安全芯片里
- **应用锁**：指纹 / 面容 / 锁屏密码
- **密码备份包**：导出成一个加密文件，换手机或重装后输密码一键恢复
- **导出到相册**（v78 新增）：把扫描件存进系统相册的「妥帖」目录

完整介绍见 [妥帖-功能介绍.md](妥帖-功能介绍.md)。

## 隐私

- 所有证件、文件**只存在你自己手机里**，没有任何服务器、不联网上传
- 没有广告、没有埋点、没有第三方统计 SDK
- 不需要 Google 服务（GMS）

## 更新日志

### v1.0.0+78（2026-09-30）

- **照片详情页新增「导出到相册」**：底部操作栏（旋转 / 剪裁 / 加页旁边）和全屏看图页都能一键导出；
