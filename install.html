妥帖 Sorted · 安装说明

目前只有安卓（Android）版本，暂没有 iPhone（iOS）、iPad、电脑版。

安装包是 APK 文件，只有安卓手机能装。

  • 大小：34.7 MB
  • 系统要求：Android 7.0（含）以上
  • 下载下来的文件名类似 sorted-v1.0.0-80-arm64-release.apk

一、先确认你的手机能装

手机系统能不能装
小米 / 红米（MIUI、澎湃 HyperOS）✅ 可以
华为 EMUI 12 及以下、鸿蒙 HarmonyOS 2～4✅ 可以
华为 HarmonyOS NEXT / 鸿蒙 5.0 及以上（纯血鸿蒙）❌ 装不了，纯血鸿蒙不再支持安卓 APK
荣耀 MagicOS✅ 可以
OPPO / 一加（ColorOS）✅ 可以
vivo / iQOO（OriginOS）✅ 可以
三星（One UI）✅ 可以
其他安卓 7.0 以上机型✅ 可以
iPhone / iPad❌ 暂无 iOS 版

不确定自己是不是纯血鸿蒙：打开「设置 → 关于本机」，看「HarmonyOS 版本」。

显示 5.0 / NEXT 的就是纯血鸿蒙，装不了；显示 2～4 的可以正常装。

二、安装步骤（共三步）

第 1 步：下载 APK

用手机自带浏览器（或 Chrome、Edge、夸克等）打开下载页，点「下载 APK 安装包」。

⚠️ 用微信、QQ 里打开的链接下载容易失败或被拦截。

遇到这种情况，点右上角「···」→「在浏览器中打开」。

下载完一般在「下载」目录，文件名 sorted-v1.0.0-80-arm64-release.apk。

第 2 步：给浏览器开「安装未知应用」权限（最关键）

安卓手机默认不允许安装应用商店以外的安装包，会提示「禁止安装」「未知来源」或者直接没反应。 需要先允许「你用来下载的那个浏览器」安装应用。

最快的办法（所有品牌通用）：打开手机「设置」，在顶部的搜索框里搜 「安装未知应用」（有的机型叫「未知来源」「外部来源应用」），点进去， 在列表里找到你下载用的浏览器（系统浏览器 / Chrome / 夸克…），把开关打开。

下面的路径供参考，找不到就用上面的搜索办法：

  • 小米 / 红米（澎湃 HyperOS / MIUI） 设置 → 隐私保护 → 特殊权限设置 → 安装未知应用 → 选浏览器 → 允许 （部分机型：设置 → 应用设置 → 应用管理 → 权限 → 安装未知应用）
  • 华为（EMUI / HarmonyOS 2～4） 设置 → 安全 → 更多安全设置 → 安装未知应用 → 选浏览器 → 允许 若开了「纯净模式」：设置 → 系统和更新 → 纯净模式 → 关闭，或安装时点「继续安装」
  • 荣耀（MagicOS） 设置 → 安全 → 更多安全设置 → 安装未知应用 → 选浏览器 → 允许
  • OPPO / 一加（ColorOS） 设置 → 权限与隐私 → 权限 → 安装未知应用 → 选浏览器 → 允许
  • vivo / iQOO（OriginOS） 设置 → 应用与权限 → 权限管理 → 权限 → 安装未知应用 → 允许
  • 三星（One UI） 设置 → 应用 → 右上角「⋮」→ 特殊访问 → 安装未知应用 → 选浏览器 → 允许
  • 原生安卓 / 其他机型 设置 → 应用 → 特殊应用访问 → 安装未知应用 → 选浏览器 → 允许

第 3 步：安装

回到浏览器的下载列表点安装包，或者用「文件管理」打开 下载 目录里的 APK， 按提示点「安装」即可。

安装过程中手机可能会弹出这些提示，都属于正常现象，选「继续」就行：

  • 「此应用可能有害 / 未知来源应用」→ 点继续安装 / 仍要安装
  • 「未通过安全检测 / 未上架应用商店」→ 点继续 / 了解风险后安装
  • 小米安全扫描、华为病毒扫描 → 等它扫完，点继续安装
  • 要求输入锁屏密码 / 验证指纹 → 正常输入

三、第一次打开

  • 会请求相机权限 → 允许（拍照扫描要用）
  • 会请求相册 / 图片权限 → 允许（从相册导入要用）
  • 想开应用锁（指纹 / 面容 / 锁屏密码）→ 在左上角图标 → 设置里打开

识别功能完全离线：中文识别模型已经打进安装包里， 不需要联网、不需要 Google 服务（GMS）、不需要登录任何账号，飞行模式也能用。

四、升级安装（分两种情况）

情况 A：你已经装的是 v69 或更新的版本

直接下载新版 APK 覆盖安装就行，扫描件、分类、设置全部保留，不用重新导入。 以后每次升级都是这样。

情况 B：你装的是 v68 或更早的版本 ⚠️ 必须按顺序做

v69 换成了正式签名，和旧版签名不同，安卓不允许直接覆盖安装 （会提示「安装失败」「未安装」或直接覆盖不了）。必须按下面四步来：

  1. 先打开旧版 → 左上角图标 → 设置 → 导出备份包 设一个密码（≥6 位，自己另外记好，忘了找不回来），存到手机或网盘里
  2. 卸载旧版（长按图标卸载，或在设置 → 应用管理里卸载）
  3. 安装下载好的新版 APK
  4. 打开新版 → 设置 → 导入备份包，输入密码，文件全部回来

❗ 顺序千万别反。先卸载再想起来备份，应用数据就随卸载一起删掉了，找不回来。

五、遇到问题怎么办

现象原因 / 解决办法
提示「解析包失败」「安装包损坏」文件没下载完整。删掉重新下载一次；别用微信内置浏览器下载
提示「安装失败」「应用未安装」「与已安装的应用签名不同」手机上装的是 v68 或更早的版本，签名不一样。先看上面「四、情况 B」，先导出备份包再卸载重装
点了安装没反应 / 一直转圈第 2 步的「安装未知应用」没开。确认开的是你下载用的那个浏览器的权限
被提示「存在风险」不敢点本应用不联网、不上传任何数据，也没有广告，可以放心继续安装
找不到下载的文件打开「文件管理 → 下载」，或在浏览器里点「下载记录」直接打开
华为提示「纯净模式」不允许设置 → 系统和更新 → 纯净模式 → 关闭，装完可以再打开
安装后打不开 / 闪退确认系统版本在 Android 7.0 以上；重启手机再试
换手机后扫描件打不开证件图是用旧手机的安全芯片密钥加密的，需要用旧手机导出备份包再导入新手机（设置 → 导出备份包）

六、隐私说明（装之前可以看看）

  • 所有证件、文件只存在你自己手机里，没有任何服务器、不联网上传
  • 证件类图片在手机上是以密文保存的，密钥存在手机的安全芯片里，取不出来
  • 没有广告、没有埋点、没有第三方统计 SDK
