软件介绍 一个装证件的抽屉。纸质的证件、发票、合同、说明书，随手一拍就自动收好、 自动认出是什么、自动归好类，要用的时候一搜就出来。不用注册登录，全程在自己手机里。
能做什么
  • 拍一下就归档：自动找纸的边缘、裁掉背景、把歪的扶正；一份文件可以分好几页拍，合成一份
  • 自动认出是什么：身份证 / 护照 / 驾驶证 / 行驶证 / 银行卡 / 营业执照 / 发票 / 合同 / 说明书…，还能提取证件号、有效期、车牌号这些关键信息
  • 自动起名字：不再是「扫描件 1」，用机构名、票据种类当标题
  • 一搜就找到：搜标题，也搜纸上的全部文字——打个商家名就能把那张发票翻出来
  • 证件单独上锁：证件类加密保存，还能给整个应用加指纹 / 面容 / 锁屏密码
  • 换手机也不怕丢：加密备份包一键导出导入，换机原样恢复
  • 完全离线：识别就装在应用里，不联网、不上云、没有任何服务器

本版更新（v97）
  • 修复实拍弱边界场景自动选边严重错误。小票压在浅色桌面、暗光环境下，扫描引擎原本会把纸内的折痕、纹理误判成边界（锁住一个倾斜四边形，框住纸内一块而非整张纸）——和 memo+ 是同源的同一种问题。
  • 本版移植 memo+ 的弱边界补全：在低阈值下补找候选四边形，要求它包住强检测结果、面积足够大、且通过全分辨率颜色校验（确认框内确实是纸、框外是背景），从而正确框住整张小票。
  • 识别、自动摆正（v93 判据）、详情页功能均不变；不联网上传、不新增权限；签名不变可直接覆盖安装 v96。
