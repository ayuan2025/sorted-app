软件介绍 一个装证件的抽屉。纸质的证件、发票、合同、说明书，随手一拍就自动收好、 自动认出是什么、自动归好类，要用的时候一搜就出来。不用注册登录，全程在自己手机里。
能做什么
  • 拍一下就归档：自动找纸的边缘、裁掉背景、把歪的扶正；一份文件可以分好几页拍，合成一份
  • 自动认出是什么：身份证 / 护照 / 驾驶证 / 行驶证 / 银行卡 / 营业执照 / 发票 / 合同 / 说明书…，还能提取证件号、有效期、车牌号这些关键信息
  • 自动起名字：不再是「扫描件 1」，用机构名、票据种类当标题
  • 一搜就找到：搜标题，也搜纸上的全部文字——打个商家名就能把那张发票翻出来
  • 证件单独上锁：证件类加密保存，还能给整个应用加指纹 / 面容 / 锁屏密码
  • 换手机也不怕丢：加密备份包一键导出导入，换机原样恢复
  • 完全离线：识别就装在应用里，不联网、不上云、没有任何服务器

本版更新（v100）
  • 修复「扫社保卡时把周围背景整片框进来」：v99 的落差判据在「卡放白纸/浅色垫子上」场景方向反了——白纸对深色桌面的落差反而强于蓝卡对白纸，白纸不被删、整片背景进了框。本版在颜色落差之外新增「内容密度」判据：文件内部有字有图（颜色起伏明显），空白承载面是均匀的——内框内容明显多于外框环带且环带近乎空白就删外框。实测白纸场景从框住 0.736 的白纸修正为 0.277 的卡；身份证/小票/深色背景等全部历史场景无回退。
  • 修复「导入后自动颠倒放置」：180° 翻转门槛从「倒朝向比正朝向高 0.8 分就翻」收紧为「倒朝向必须确凿像人话（≥2.0）且原朝向明确读不成话（<1.0）才翻」——社保卡这类稀疏文字卡片正着拍也常只读出一两行，差 0.8 极易把正图翻反。宁可留一个颠倒图，也不把正图转歪。
  • 新增社保卡回归测试 + 摆正守卫用例；识别、详情页、检查更新均不变；不联网上传、不新增权限；签名不变可直接覆盖安装 v99。
